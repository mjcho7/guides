#01AI 활용꿀팁 실습 · 보도자료 작성

보도자료,
기자처럼 쓰고 싶으신가요?

프로젝트 지침으로 보도자료 제목·부제목 쓰기

2026년 11월 화면 기준

프로젝트란?

규칙(지침)과 참고 자료를 저장해 두는 AI 작업 공간이에요. 그 안에서 여는 대화는 저장한 규칙과 자료를 늘 따라요.

0

실습 자료 내려받기

이번 실습은 AI가 참고할 보도자료 한 편으로 해요. 먼저 내 컴퓨터에 저장해 두세요.

참고 보도자료(겨울숭어축제)PDF · 1쪽 · 실습용 가상 자료
내려받기

제목 "숭어는 추울 때 먹어야 제맛!", 부제목 "'2026 한빛 겨울숭어축제' 12월 24일 한빛항 일원서 개막"처럼 쓰인 보도자료예요. AI가 이 방식을 따라 써요.

쓰시는 AI를 고르면 1~3단계 안내가 바뀌어요. AI 화면은 자주 바뀌니, 버튼 이름이 다르면 메뉴에서 “프로젝트(Project)”라는 단어를 찾아보세요.

1

새 프로젝트 만들기

  1. 왼쪽 메뉴에서 새 프로젝트를 눌러요.
  2. 이름을 보도자료 작성으로 적고 만들어요.
  1. 왼쪽 메뉴에서 Projects (프로젝트)를 눌러요.
  2. 오른쪽 위 + New Project (새 프로젝트)를 눌러요.
  3. 이름을 보도자료 작성으로 적고 만들어요.
2

지침에 제목 작성 원칙 넣기

  1. 프로젝트 화면 오른쪽 위 ••• → 프로젝트 설정을 눌러요.
  2. 지침 칸에 아래 내용을 붙여넣어요.
  1. 프로젝트 안에서 Set project instructions (프로젝트 지침 설정)을 눌러요.
  2. 아래 내용을 붙여넣고 Save instructions (저장)을 눌러요.
너는 10년 차 기자 출신 홍보 담당자다.
사용자가 행사명, 날짜, 장소를 입력하면 보도자료의 제목과 부제목을 쓴다.

[제목]
- 비유나 대구를 살려 짧고 인상적으로 쓴다. 15자 안팎.
- 행사의 성격이나 의미가 한눈에 떠오르게 쓴다.
- 예: 숭어는 추울 때 먹어야 제맛!

[부제목]
- 한 줄로 쓴다.
- 입력한 행사명·날짜·장소를 모두 넣어 "'[행사명]' [날짜] [장소]서 개막" 형식으로 쓴다.
- 예: '2026 한빛 겨울숭어축제' 12월 24일 한빛항 일원서 개막

[공통 원칙]
- 문체와 형식은 첨부한 보도자료를 참고한다.
- 입력하지 않은 날짜, 장소, 숫자, 프로그램은 지어내지 않는다.
- 홍보성 과장 표현("최고의", "역대급")은 쓰지 않는다.

[출력 형식] 아래 두 줄만 쓰고, 설명은 덧붙이지 않는다.
제목: ...
부제목: ...
3

참고 보도자료 올리기

  1. 프로젝트 화면에서 소스 탭을 눌러요.
  2. + 소스 추가를 누르고, 0단계에서 받은 PDF를 올려요.
  1. 프로젝트 화면 오른쪽 Files (파일)의 +를 눌러요.
  2. 0단계에서 받은 PDF를 올려요.

내 업무에서는? 기사로 잘 실렸던 우리 기관의 지난 보도자료 1~2건을 올리세요. AI가 그 문체를 따라 써요.

4

질문하고 다듬기

프로젝트 안에서 새 대화를 열고, 행사명·날짜·장소만 보내 보세요. 규칙은 다시 쓰지 않아도 돼요.

국제탈춤페스티벌, 9월 26일, 탈춤공원
국악한마당, 10월 17일, 한빛문화예술관
이런 형태로 나오면 성공

제목: 탈 쓰고, 흥을 잇다!
부제목: '국제탈춤페스티벌' 9월 26일 탈춤공원서 개막

제목: 우리 가락, 흥을 돋우다!
부제목: '국악한마당' 10월 17일 한빛문화예술관서 개막

제목은 매번 조금씩 달라져요. 마음에 들 때까지 "다른 제목으로 다시"라고 보내 보세요. 부제목 형식은 그대로 유지돼요.

결과가 어긋나면? 대화가 아니라 지침을 고치세요. 예: "제목에 기관명을 넣는다"를 한 줄 추가하면 다음부터 계속 적용돼요.

+

내 업무에 써 보기

글마다 프로젝트를 하나씩 만들고, 지침과 참고 자료만 바꿔 넣으면 돼요. [ ] 부분은 우리 기관에 맞게 고쳐 주세요.

행사 홍보글행사명·날짜만 넣으면 SNS 게시글 완성▼ 
사용자가 행사명과 날짜를 입력하면 [기관명] 인스타그램 게시글을 작성한다.
- 본문 2줄, 밝고 친근한 어조로 쓴다.
- 행사명과 날짜를 본문에 반드시 넣는다.
- 확인되지 않은 장소, 프로그램, 참여 방법은 추가하지 않는다.
- 본문 아래에 해시태그를 정확히 4개 쓴다.
기관 소식지 기사메모만 넣으면 소식지 기사 완성▼ 
사용자가 행사·사업 메모를 입력하면 [기관명] 소식지 기사를 작성한다.
- 제목은 짧고 인상적으로, 부제목은 핵심 사실을 한 줄로 쓴다.
- 본문은 3문단 이내, 중요한 내용부터 쓴다.
- 메모에 없는 수치, 프로그램, 관계자 발언은 만들지 않는다.
- 문체는 첨부한 지난 소식지 기사를 참고한다.
카드뉴스 문구알릴 내용만 넣으면 5장 문구 완성▼ 
사용자가 알릴 내용을 입력하면 카드뉴스 5장 문구를 작성한다.
- 1장: 눈길을 끄는 제목 한 줄
- 2~4장: 한 장에 한 가지 핵심, 2줄 이내
- 5장: 일시, 장소, 문의처
- 입력하지 않은 정보는 [ ]로 비워 둔다.

꼭 지켜 주세요

  • 개인정보, 비공개 문서, 내부 자료는 입력하지 마세요.
  • AI 결과는 초안이에요. 날짜·이름·사실은 반드시 직접 확인하세요.
  • 소속 기관의 AI 사용 지침이 있다면 그 기준을 먼저 따르세요.
