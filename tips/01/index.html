프로젝트 지침으로 반복 업무 자동화하기

2026년 10월 화면 기준

프로젝트란?

규칙(지침)을 저장해 두는 AI 작업 공간이에요. 그 안에서 여는 대화는 저장한 규칙을 늘 따라요.

쓰시는 AI를 고르면 1~3단계 안내가 바뀌어요. AI 화면은 자주 바뀌니, 버튼 이름이 다르면 메뉴에서 “프로젝트(Project)”라는 단어를 찾아보세요.

1

새 프로젝트 만들기

  1. 왼쪽 메뉴에서 New project (새 프로젝트)를 눌러요.
  2. 이름을 보도자료 첫 문단으로 적고 만들어요.
  1. 왼쪽 메뉴에서 Projects (프로젝트)를 눌러요.
  2. 오른쪽 위 + New Project (새 프로젝트)를 눌러요.
  3. 이름을 보도자료 첫 문단으로 적고 만들어요.
+ New project
Projects

주황 테두리 버튼을 찾으세요

2

지침에 업무 규칙 넣기

  1. 프로젝트 안에서 오른쪽 위 ••• → Project settings (프로젝트 설정)을 눌러요.
  2. 지침(Instructions) 칸에 아래 업무 규칙을 붙여넣고 저장해요.
  1. 프로젝트 안에서 Set project instructions (프로젝트 지침 설정)을 눌러요.
  2. 아래 업무 규칙을 붙여넣고 Save instructions (저장)을 눌러요.
사용자가 행사명과 날짜를 입력하면 한빛시 보도자료의 첫 문단을 작성한다.
- 첫 문장은 반드시 "한빛시는 [날짜] '[행사명]'을(를) 개최한다고 밝혔다."로 쓴다.
- 이어서 행사 취지를 1~2문장 더해 전체 2~3문장으로 쓴다.
- 입력하지 않은 장소, 수치, 프로그램, 인용문, 관계자 발언은 만들지 않는다.
- 객관적이고 간결한 보도자료 문체를 쓴다.
- 제목, 목록, 별도 설명은 덧붙이지 않는다.
3

예시 자료 올리기

우리 기관의 지난 보도자료 1~2건을 프로젝트 파일로 올려 두면, 문체와 형식을 더 정확하게 따라요.

  1. 프로젝트 화면에서 Add files (파일 추가)를 눌러요.
  2. 지난 보도자료 파일(PDF·한글 변환 문서 등)을 올려요.
  1. 프로젝트 화면 오른쪽 Files (파일)의 +를 눌러요.
  2. 지난 보도자료 파일(PDF·한글 변환 문서 등)을 올려요.

지침에 한 줄 더! "올린 예시 보도자료의 문체를 따른다"를 지침 마지막에 추가하면 더 좋아요. 예시 자료가 없으면 이 단계는 건너뛰어도 돼요.

4

질문하고 다듬기

프로젝트 안에서 새 대화를 열고, 아래 중 하나를 복사해 보내 보세요. 규칙은 다시 쓰지 않아도 돼요.

가을 독서축제, 11월 8일
청소년 영화제, 11월 22일
겨울 음악회, 12월 13일
이런 형태로 나오면 성공

한빛시는 11월 8일 '가을 독서축제'를 개최한다고 밝혔다. 이번 축제는 독서의 계절을 맞아 시민들이 책과 더 가까워질 수 있도록 마련됐다.

다른 행사도 보내서 형식이 같은지 확인하세요. 세 개를 모두 보내 보면 첫 문장이 늘 같은 틀로 나오는지 바로 보여요.

결과가 어긋나면? 대화가 아니라 지침을 고치세요. 예: "마지막 문장은 '자세한 내용은 [담당부서]로 문의하면 된다'로 끝낸다"를 한 줄 추가하면 다음부터 계속 적용돼요. 이렇게 질문 → 확인 → 지침 고치기를 반복하면 우리 업무에 꼭 맞는 지침이 돼요.

+

내 업무에 써 보기

업무마다 프로젝트를 하나씩 만들고, 지침만 바꿔 넣으면 돼요. [ ] 부분은 우리 기관에 맞게 고쳐 주세요.

행사 홍보글행사명·날짜만 넣으면 SNS 게시글 완성▼ 
사용자가 행사명과 날짜를 입력하면 [기관명] 인스타그램 게시글을 작성한다.
- 본문 2줄, 밝고 친근한 어조로 쓴다.
- 행사명과 날짜를 본문에 반드시 넣는다.
- 확인되지 않은 장소, 프로그램, 참여 방법은 추가하지 않는다.
- 본문 아래에 해시태그를 정확히 4개 쓴다.
회의 안내 문자회의명·일시만 넣으면 안내 문자 완성▼ 
사용자가 회의명과 일시를 입력하면 참석자에게 보낼 안내 문자를 작성한다.
- 90자 이내로 작성한다.
- 회의명, 일시, 장소, 준비물 순서로 쓴다.
- 입력하지 않은 정보는 [ ]로 비워 둔다.
- 정중하고 간결한 문체를 쓴다.
출장 결과 보고메모만 넣으면 □○ 개조식 요약▼ 
사용자가 출장 메모를 입력하면 출장 결과 보고를 작성한다.
- □(대제목), ○(세부 내용) 개조식으로 쓴다.
- 출장 개요 / 주요 내용 / 향후 계획 순서로 정리한다.
- A4 반 페이지 이내로 쓴다.
- 메모에 없는 내용은 추가하지 않는다.

꼭 지켜 주세요

  • 개인정보, 비공개 문서, 내부 자료는 입력하지 마세요.
  • AI 결과는 초안이에요. 날짜·이름·사실은 반드시 직접 확인하세요.
  • 소속 기관의 AI 사용 지침이 있다면 그 기준을 먼저 따르세요.
