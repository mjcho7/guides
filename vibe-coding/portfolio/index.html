바이브 코딩으로 만든 실제 사례

코드를 직접 짜지 않고 말로 설명해 만든 업무 도구입니다. 만들기 전에 열어 보고 “나는 무엇을 만들 수 있을까” 떠올려 봅니다.

  • 엑셀 한눈에강사 제작

    엑셀 표를 올리면 결론 문장, 핵심 숫자 카드, 그래프로 정리해 줍니다. 병합 셀·소계가 있어도 읽고, 기간·항목 필터, 원본 확인, 엑셀·PDF 저장까지 됩니다. 모든 처리는 브라우저 안에서만 이루어집니다.

    사이트 열어 보기 ↗
  • 온봄 · 복지서비스 신청 안내화성시 AI 챔피언 수료 후 제작

    필요한 복지를 찾아 신청 방법을 안내하는 플랫폼입니다. 업무 화면별 담당자 메모와, 민원인에게 줄 안내 사항을 복사·인쇄하는 기능이 있습니다.

실습 파일바탕화면에 새로 만드는 my-intro 폴더 · 사용 도구: Codex 앱

진행 단계

1작업 폴더 만들고 Codex로 열기

바탕화면에 my-intro 폴더를 만듭니다. 내 사진을 쓰려면 photo.jpg라는 이름으로 넣어 둡니다. Codex 앱에서 이 폴더를 프로젝트로 추가하고 새 대화를 엽니다.

확인할 것
  • Codex 화면 위쪽에 my-intro 폴더가 작업 위치로 보이나요?

2프롬프트 조립하기

아래에서 내 정보를 채우고 분위기·구성·효과를 고르면 프롬프트가 완성됩니다. 복사해서 Codex에 보냅니다.

Dribbble · 개인 웹사이트 디자인 ↗Dribbble ↗노트폴리오 · 국내 창작자 포트폴리오 ↗핀터레스트 · 웹디자인 포트폴리오 ↗Pretendard · 한글 웹폰트 ↗눈누 · OFL 무료 한글 폰트 ↗

근사하게 만드는 요령
  • 휴대폰에서 먼저 보기 좋아야 합니다. 화려한 효과보다 글자 크기, 여백, 버튼 크기가 중요합니다. 휴대폰에는 마우스가 없어서 ‘마우스를 올리면’ 효과는 보이지 않습니다.
  • 분위기는 형용사 하나보다 장면으로 설명합니다. 예: “토스 앱처럼 제목이 아주 크고 단순한”, “배민처럼 문구가 재치 있는”
  • 참고 사이트 주소를 주고 ‘무엇을’ 가져올지 적습니다. 화면 캡처 이미지를 함께 첨부하면 더 정확합니다.
  • 색은 2~3개, 폰트는 1~2개만 정합니다. 많을수록 산만해집니다.
  • 정보가 적어도 괜찮습니다. ‘풍부하게’나 ‘아주 창의적으로’를 고르면 AI가 주어진 정보로 문장과 섹션을 살려 씁니다. 연도·숫자 같은 사실만 지어내지 않게 합니다.
① 내 정보
② 분위기 (하나)
③ 구성 (여러 개)
③-1 표현 수준 (하나)
정보를 조금만 넣어도 ‘풍부하게’를 고르면 AI가 문장과 섹션을 살려서 씁니다.
④ 효과 (선택 · 1~2개면 충분)
④-1 재미있는 기능 (선택 · 2~3개 추천)
모두 휴대폰에서 터치로 작동하게 만들어 달라고 프롬프트에 들어갑니다. 너무 많이 고르면 산만해집니다.
⑤ 색과 폰트
⑥ 참고 사이트 (선택)
Codex에게 · 위에서 고른 내용이 자동으로 들어갑니다


확인할 것
  • 폴더에 index.html이 생겼고, 더블클릭하면 브라우저에서 열리나요?
  • 연도·숫자·수상처럼 사실로 보이는 내용이 새로 지어지지 않았나요? [수정 필요] 자리가 있으면 내 정보로 채웁니다.
  • 휴대폰 크기(브라우저 창을 좁게)에서도 깨지지 않나요?
  • 재미있는 기능을 골랐다면, 휴대폰에서 터치로 작동하고 움직이는 요소가 글자를 가리지 않나요?
3한 가지씩 다듬기
마음에 안 드는 곳을 한 번에 하나씩 말로 고칩니다. 아래 예시를 골라 써도 됩니다.
Codex에게 · 내용 더 풍부하게
지금 페이지가 너무 단순해. 내가 준 정보를 바탕으로 섹션마다 문장을 더 풍부하게 늘리고, ‘일하는 방식’과 ‘함께 일하면 좋은 점’ 섹션을 새로 만들어줘. 연도·숫자 같은 사실 정보는 지어내지 마.
Codex에게 · 콘셉트 입히기
나를 한마디로 표현하는 콘셉트(예: ‘기후 데이터 번역가’)를 3개 제안해줘. 내가 하나 고르면 그 콘셉트로 첫 화면 문구와 페이지 전체 분위기를 다시 꾸며줘.
Codex에게 · 재미 더하기
페이지에 재미있는 기능을 하나 더해줘. 오리지널 캐릭터가 가끔 화면 아래를 걸어 지나가고, 누르면 폴짝 뛰며 ‘반가워요!’ 말풍선을 띄워줘. 휴대폰에서도 터치로 되게 하고 글자는 가리지 마.
Codex에게 · 첫 화면 강조
첫 화면을 더 임팩트 있게 바꿔줘. 이름을 크게 하고, 배경에 은은하게 움직이는 그라데이션을 넣어줘.
Codex에게 · 사진 넣기
폴더의 photo.jpg를 사진 자리에 원형으로 넣어줘.
Codex에게 · 차분하게 정리
전체적으로 너무 화려해. 색은 2개만 남기고 차분하게 정리해줘.
Codex에게 · 참고 사이트 반영 · 색칠된 부분을 내 것으로
참고 사이트 주소의 레이아웃·색감·글꼴 중 가져올 점을 참고해서 디자인을 바꿔줘. 내용은 그대로 둬.
Codex에게 · 모바일 점검
휴대폰 화면 크기에서 깨지거나 겹치는 곳이 없는지 확인하고 고쳐줘. 글자와 버튼이 작으면 키워줘.
확인할 것
  • 고친 곳 말고 다른 곳은 그대로인가요? Ctrl+F5로 새로고침해서 확인합니다.
4Vercel 배포 스킬 설치
Codex에는 OpenAI가 공개한 vercel-deploy 스킬이 있습니다. 플러그인을 따로 연결하지 않아도, 이 스킬을 설치하면 Codex가 Vercel에 바로 올려 줍니다. ‘다른 사람이 만든 스킬을 설치’해서 쓰는 방법입니다.
Codex에게
Vercel에 배포할 수 있게 OpenAI 스킬 카탈로그의 vercel-deploy 스킬을 설치해줘.
확인할 것
  • Codex의 스킬 목록에 vercel-deploy가 보이나요?
주의
  • 설치 후 스킬이 바로 안 보이면 Codex 앱을 껐다가 다시 켭니다.
5Vercel에 배포하기
배포를 맡깁니다. Vercel 로그인 없이도 임시 주소(Preview URL)와, 내 계정으로 가져오는 주소(Claim URL)가 나옵니다.
Codex에게
이 폴더의 자기소개 페이지를 vercel-deploy 스킬로 Vercel에 배포해줘.
끝나면 Preview URL과 Claim URL을 알려줘.
확인할 것
  • Preview URL을 휴대폰으로 열면 내 페이지가 보이나요?
  • 옆 사람에게 주소를 보내 열리는지 확인했나요?
주의
  • 배포하려면 인터넷 접속 권한이 필요합니다. Codex가 권한을 물으면 승인합니다.
  • 배포한 주소는 아는 사람 누구나 볼 수 있습니다. 집 주소, 개인 휴대폰 번호처럼 공개하면 안 되는 정보는 넣지 않습니다.
6내 계정으로 가져오기
Claim URL을 그냥 두면 임시 배포라 일정 기간 뒤 사라집니다. Claim URL을 열고 Vercel에 가입·로그인하면 내 프로젝트로 옮겨져 계속 유지됩니다.
Vercel 가입 (무료 Hobby) ↗Vercel 대시보드 ↗
확인할 것
  • Vercel 대시보드에 내 프로젝트가 보이나요?
7고치고 다시 배포
페이지를 한 군데 고친 뒤 다시 배포합니다.
Codex에게 · 색칠된 부분을 내 것으로
고칠 내용을 고치고 Vercel에 다시 배포해줘. 새 주소를 알려줘.
Codex 없이 직접 올리는 방법 · Vercel Drop
  1. 완성된 index.html이 든 my-intro 폴더를 준비합니다.
  2. vercel.com/drop을 열고 폴더를 화면에 끌어다 놓습니다.
  3. 로그인돼 있으면 팀과 프로젝트 이름(영문)을 정하고 Deploy를 누릅니다. 로그인하지 않으면 바로 임시 배포됩니다.
  4. https://프로젝트이름.vercel.app 주소가 나오면 열어 확인합니다.
확인할 것
  • 새 주소에서 고친 내용이 보이나요?
