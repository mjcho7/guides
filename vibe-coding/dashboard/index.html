목표
예술의전당 공연·전시 입장객 데이터로 대시보드를 만들고 배포한다
재료
예술의전당_공연및전시_입장객현황_통합_20251231.xlsx (분석용 데이터 시트, 2011~2025년, 51,938행)
결과물
더블클릭으로 열리는 대시보드 HTML, 누구나 접속할 수 있는 vercel.app 주소
핵심
“코드를 알려줘”가 아니라 “작동하는 도구를 만들어줘”. 기능은 한 번에 하나씩 더하고, 매번 “기존 기능은 변경하지 마”를 붙인다
시작 전에 알아 둘 데이터 특징
  • 엑셀에는 시트가 4개 있습니다. 분석에는 분석용 데이터 시트를 씁니다. 나머지(통합 안내, 연도별 요약, 전처리 현황)는 설명과 점검용입니다.
  • 공연은 2011년부터, 전시는 2023년부터 들어 있습니다. 공연과 전시를 합친 연도별 추이는 2023년에 갑자기 늘어난 것처럼 보일 수 있습니다.
  • 전시 행에는 시간과 시간대가 비어 있습니다. 시간대 분석은 공연 기준으로 봅니다.
  • 연도에 따라 이름이 다르게 적힌 장소가 있습니다. 예: 서울서예박물관(2011~2022)과 서예박물관(2023~), 한가람디자인미술관과 디자인미술관, IBK챔버홀과 IBK기업은행챔버홀.
  • 행 하나는 공연 회차 또는 전시 일자 하나입니다. 관객 수는 관객수 열, 장소는 장소(표준) 열을 씁니다.

1단계

데이터 확인과 설계

대시보드를 만들기 전에 KPI와 분석 질문부터 받습니다. 개요에서 내려받은 엑셀 파일을 넣은 seoul-arts-dashboard 폴더를 Codex 앱에서 프로젝트로 열고 시작합니다.

Codex에게
폴더의 예술의전당 공연·전시 입장객 현황 엑셀 파일을 분석해줘.
‘분석용 데이터’ 시트를 기준으로 하고, 다른 시트는 데이터 설명으로 참고해줘.
주요 컬럼을 분류하고 입장객 현황을 파악하기 위한
KPI 5개와 분석 질문을 제안해줘.
아직 대시보드는 만들지 마.
확인할 것
  • 연도·월·분야·장소(표준)·구분·공연·전시명·관객수·유료·무료 같은 컬럼이 구분됐나요?
  • KPI 5개가 데이터에 실제로 있는 컬럼으로 계산되나요?
  • 전시가 2023년부터만 있다는 점을 짚었나요?
  • 아직 HTML을 만들지 않았나요?

9단계

Vercel로 배포하기

대시보드를 배포합니다. Vercel 로그인 없이도 임시 주소(Preview URL)와, 내 계정으로 가져오는 주소(Claim URL)가 나옵니다.

Codex에게
이 대시보드를 Vercel에 배포해줘.
대시보드 HTML 파일을 index.html로 맞춰서 배포하고,
Preview URL과 Claim URL을 알려줘.

Vercel 가입 (무료 Hobby) ↗Vercel 대시보드 ↗

확인할 것
  • Preview URL을 휴대폰에서 열면 대시보드가 보이나요?
  • 배포된 화면에서도 필터와 차트가 동작하나요?
  • Claim URL을 열고 Vercel에 로그인해 내 계정으로 가져왔나요? 그냥 두면 임시 배포라 일정 기간 뒤 사라집니다.
주의
  • 배포하려면 인터넷 접속 권한이 필요합니다. Codex가 권한을 물으면 승인합니다.
  • 배포한 주소는 아는 사람 누구나 볼 수 있습니다. 공개 데이터만 올리고, 내부 자료나 개인정보가 담긴 대시보드는 배포하지 않습니다.

막힐 때

이럴 때이렇게
기능을 더했더니 예전 기능이 망가졌다“망가진 기능이 방금 더한 기능을 넣은 뒤로 안 돼. 이번 변경 전 동작으로 되돌리고, 새 기능은 유지해줘.”라고 보냅니다.
HTML이 하얗게만 나온다브라우저에서 F12 → Console의 빨간 오류를 복사해 그대로 보냅니다.
HTML 파일이 너무 커서 느리다“대시보드에 쓰지 않는 열은 빼고, 데이터를 더 가볍게 넣어줘. 기존 기능은 변경하지 마.”라고 보냅니다.
차트 일부가 안 나온다“Excel을 업로드했는데 일부 차트가 표시되지 않아. 현재 코드와 오류 화면을 분석해서 원인을 찾고 수정해줘.”라고 보냅니다.
변경이 화면에 안 보인다브라우저에서 Ctrl+F5로 새로고침합니다.

한 번에 만드는 통합 프롬프트

단계별로 해 본 뒤, 요구사항을 한 번에 다 적으면 어떻게 되는지 비교할 때 씁니다. Codex 새 대화에서 보냅니다.

통합 프롬프트 펼치기
Codex에게 · 통합 프롬프트
아래 요구사항을 모두 만족하는 단일 HTML 파일 기반 인터랙티브 대시보드를 만들어줘.
데이터는 폴더의 예술의전당 공연·전시 입장객 현황 엑셀 파일이고, ‘분석용 데이터’ 시트를 기준으로 해.
목표는 “엑셀·CSV 파일(수만 행)을 업로드하면 즉시 브라우저에서 분석 가능한 예술의전당 입장객 현황 대시보드”야.
외부 서버 연결 없이, 모든 처리는 브라우저 내에서만 수행해야 해.
1. 공통
ㆍ기본 데이터(분석에 필요한 열만)·CSS·JavaScript를 HTML 내부에 포함
ㆍ연도, 분야(공연·전시), 장소, 구분(기획·대관) 필터 제공 및 AND 조건 적용
ㆍ필터 변경 시 KPI·차트·TOP10·상세표 모두 즉시 갱신
ㆍ흰 배경, 공연장과 미술관에 어울리는 차분한 색상, 공연·전시는 일관된 구분 색
2. 분석
ㆍKPI: 총 입장객, 공연·전시 회차(행) 수, 회차당 평균 입장객, 유료 관객 비율, 입장객 최다 장소
ㆍ연도별 입장객 추이(공연·전시 구분), 장소별 비교 차트
ㆍ월별·요일별 입장객 패턴, 공연 시간대별 입장객
ㆍ공연·전시명 입장객 TOP10
ㆍ전시는 2023년부터만 있다는 안내 문구 표시
3. 데이터 업로드
ㆍExcel/CSV 업로드 및 Drag&Drop 지원
ㆍ파일은 서버 전송 없이 브라우저에서만 처리
