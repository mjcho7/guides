바이브코딩 과정

바이브로 만들고, 올리고, 자동화하기

자동 배포 → 웹 대시보드 → DB 현황판 → RAG 챗봇

코드를 직접 짜지 않고 AI에게 말로 설명해 업무 도구를 만듭니다. 과정마다 하나씩 더 깊이 들어가, 웹페이지 한 장에서 시작해 데이터를 쌓고 문서로 답하는 챗봇까지 갑니다. 아래 순서대로 진행합니다.

  • 강사 조미정
  • 도구 Codex 앱 또는 Claude Code, GitHub, Vercel
  • 대상 코딩 경험이 없어도 됩니다
  1. 과정1

    자기소개 페이지로 자동 배포 구조 만들기

    말로 설명해 자기소개 페이지를 만들고, GitHub와 Vercel을 연결해 올리기만 하면 사이트가 저절로 바뀌는 구조를 만듭니다.

    만드는 것자기소개 웹페이지자동 배포되는 vercel.app 주소
    새로 익히는 것프롬프트로 HTML 만들기Git·GitHubVercel 자동 배포
    1-1자기소개 페이지 만들기실습 열기 →1-2GitHub·Vercel 자동 배포실습 열기 →
  2. 과정2

    웹 대시보드로 분석 자동화하기

    예술의전당 공연·전시 입장객 엑셀 데이터를 필터·차트·표가 움직이는 웹 대시보드로 만들고, 새 파일을 올리면 바로 다시 분석되게 합니다.

    만드는 것입장객 분석 대시보드
    새로 익히는 것엑셀 데이터 분석KPI·차트 설계업로드·PDF 저장결과 검증
    2예술의전당 입장객 대시보드실습 열기 →
  3. 과정3

    팀 현황판으로 DB에 데이터 쌓기

    부서원이 함께 쓰는 당직·휴가·일정 현황판을 만들어, 입력한 내용이 DB에 저장되고 다른 기기에서도 열리게 합니다.

    만드는 것로그인되는 부서 현황판
    새로 익히는 것Node.js 서버SQLite DB작업 규칙·기획서외부 공유
    3부서 운영 현황판실습 열기 →
  4. 과정4

    벡터DB를 활용한 RAG 챗봇

    내 문서를 벡터DB에 넣고, 문서 근거와 함께 답하는 챗봇을 만들어 배포합니다.

    만드는 것문서 근거로 답하는 챗봇
