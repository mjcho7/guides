엑셀 데이터로 웹 대시보드 만들기

말로 설명하면 작동하는 도구가 됩니다

먼저 자기소개 페이지로 바이브 코딩과 배포를 맛보고, 판매 데이터 엑셀로 영업관리자용 대시보드를 만들어 주소로 공유합니다. 기능은 한 번에 하나씩 더하고, 숫자는 엑셀과 직접 대조합니다.

웹과 데스크톱 어느 쪽으로도 만들 수 있습니다. 프롬프트는 같고, 파일이 어디에 생기는지와 배포 방법이 다릅니다.

처음이라면 웹으로 빠르게 맛보고, 파일이 길어지고 고칠 곳이 많아지는 대시보드는 데스크톱을 권합니다. 웹에서는 답이 길면 코드가 중간에 끊길 수 있습니다.

진행 규칙

  1. 한 번에 하나씩 지시하고, 결과를 확인한 뒤 다음 단계로 넘어갑니다.
  2. 프롬프트는 복사해서 써도 되고, 내 말로 바꿔 써도 됩니다. 색칠된 부분은 내 내용으로 바꿉니다.
  3. 단계마다 있는 ‘확인할 것’은 꼭 직접 확인합니다. 숫자는 엑셀에서 같은 조건으로 계산해 대조합니다.
  4. 데스크톱 앱이 파일 변경이나 명령 실행 허용을 물으면 내용을 읽고 허용합니다. 원본 엑셀 삭제·수정은 허용하지 않습니다.

코드를 몰라도 말로 설명하면 웹페이지가 된다. 배포까지 한 번 해 보면 2번 대시보드도 같은 방법으로 공유할 수 있다
바이브 코딩으로 만든 실제 사례

코드를 직접 짜지 않고 말로 설명해 만든 업무 도구입니다. 만들기 전에 열어 보고 “나는 무엇을 만들 수 있을까” 떠올려 봅니다.

  • 엑셀 한눈에강사 제작

    엑셀 표를 올리면 결론 문장, 핵심 숫자 카드, 그래프로 정리해 줍니다. 병합 셀·소계가 있어도 읽고, 기간·항목 필터, 원본 확인, 엑셀·PDF 저장까지 됩니다. 모든 처리는 브라우저 안에서만 이루어집니다.

실습 파일바탕화면에 새로 만드는 my-intro 폴더 · 사용 도구: 웹(ChatGPT·Claude·Gemini) 또는 데스크톱(ChatGPT·Claude Code)

진행 단계

1작업 폴더 만들고 시작하기

바탕화면에 my-intro 폴더를 만듭니다. 내 사진을 쓰려면 photo.jpg라는 이름으로 넣어 둡니다. 그다음 쓰는 도구에 따라 시작합니다.

웹 (ChatGPT·Claude·Gemini)
  1. 브라우저에서 쓰는 AI의 새 대화를 엽니다.
  2. 사진을 쓰려면 photo.jpg를 대화에 첨부합니다.
  3. 결과 HTML은 대화창의 미리보기(캔버스·아티팩트)로 보고, 내려받아 my-intro 폴더에 index.html로 저장합니다.
데스크톱 (ChatGPT 앱·Claude Code)
  1. 앱에서 작업 폴더로 my-intro를 선택하고 새 대화(세션)를 엽니다.
  2. AI가 my-intro 폴더 안에 파일을 직접 만들고 고칩니다. 따로 내려받을 필요가 없습니다.
확인할 것
  • 웹이면 새 대화를, 데스크톱이면 my-intro 폴더를 작업 위치로 열었나요?

2프롬프트 조립하기

아래에서 내 정보를 채우고 분위기·구성·효과를 고르면 프롬프트가 완성됩니다. 복사해서 AI에 보냅니다.

Dribbble · 개인 웹사이트 디자인 ↗Dribbble ↗노트폴리오 · 국내 창작자 포트폴리오 ↗핀터레스트 · 웹디자인 포트폴리오 ↗Pretendard · 한글 웹폰트 ↗눈누 · OFL 무료 한글 폰트 ↗

근사하게 만드는 요령
  • 휴대폰에서 먼저 보기 좋아야 합니다. 화려한 효과보다 글자 크기, 여백, 버튼 크기가 중요합니다. 휴대폰에는 마우스가 없어서 ‘마우스를 올리면’ 효과는 보이지 않습니다.
  • 분위기는 형용사 하나보다 장면으로 설명합니다. 예: “토스 앱처럼 제목이 아주 크고 단순한”, “배민처럼 문구가 재치 있는”
  • 참고 사이트 주소를 주고 ‘무엇을’ 가져올지 적습니다. 화면 캡처 이미지를 함께 첨부하면 더 정확합니다.
  • 색은 2~3개, 폰트는 1~2개만 정합니다. 많을수록 산만해집니다.
  • 정보가 적어도 괜찮습니다. ‘풍부하게’나 ‘아주 창의적으로’를 고르면 AI가 주어진 정보로 문장과 섹션을 살려 씁니다. 연도·숫자 같은 사실만 지어내지 않게 합니다.

확인할 것
  • my-intro 폴더에 index.html이 있고(웹은 내려받아 저장), 더블클릭하면 브라우저에서 열리나요?
  • 연도·숫자·수상처럼 사실로 보이는 내용이 새로 지어지지 않았나요? [수정 필요] 자리가 있으면 내 정보로 채웁니다.
  • 휴대폰 크기(브라우저 창을 좁게)에서도 깨지지 않나요?
  • 재미있는 기능을 골랐다면, 휴대폰에서 터치로 작동하고 움직이는 요소가 글자를 가리지 않나요?
3한 가지씩 다듬기
마음에 안 드는 곳을 한 번에 하나씩 말로 고칩니다. 아래 예시를 골라 써도 됩니다.
AI에게 · 내용 더 풍부하게
지금 페이지가 너무 단순해. 내가 준 정보를 바탕으로 섹션마다 문장을 더 풍부하게 늘리고, ‘일하는 방식’과 ‘함께 일하면 좋은 점’ 섹션을 새로 만들어줘. 연도·숫자 같은 사실 정보는 지어내지 마.
AI에게 · 콘셉트 입히기
나를 한마디로 표현하는 콘셉트(예: ‘엑셀로 숫자를 이야기로 바꾸는 사람’)를 3개 제안해줘. 내가 하나 고르면 그 콘셉트로 첫 화면 문구와 페이지 전체 분위기를 다시 꾸며줘.
AI에게 · 재미 더하기
페이지에 재미있는 기능을 하나 더해줘. 오리지널 캐릭터가 가끔 화면 아래를 걸어 지나가고, 누르면 폴짝 뛰며 ‘반가워요!’ 말풍선을 띄워줘. 휴대폰에서도 터치로 되게 하고 글자는 가리지 마.
AI에게 · 첫 화면 강조
첫 화면을 더 임팩트 있게 바꿔줘. 이름을 크게 하고, 배경에 은은하게 움직이는 그라데이션을 넣어줘.
AI에게 · 사진 넣기
폴더의 photo.jpg를 사진 자리에 원형으로 넣어줘.
AI에게 · 참고 사이트 반영 · 색칠된 부분을 내 것으로
참고 사이트 주소의 레이아웃·색감·글꼴 중 가져올 점을 참고해서 디자인을 바꿔줘. 내용은 그대로 둬.
AI에게 · 모바일 점검
휴대폰 화면 크기에서 깨지거나 겹치는 곳이 없는지 확인하고 고쳐줘. 글자와 버튼이 작으면 키워줘.
확인할 것
  • 고친 곳 말고 다른 곳은 그대로인가요? 웹은 새로 받은 파일로 바꿔 저장하고, 데스크톱은 Ctrl+F5로 새로고침해서 확인합니다.
4Vercel에 배포하기
자기소개 페이지를 인터넷에 올려 주소로 공유합니다. 웹에서 만들었다면 Vercel Drop으로 직접 올리고, 데스크톱이라면 AI에게 맡길 수 있습니다.
웹에서 만든 경우 · Vercel Drop으로 직접 올리기
  1. 완성된 HTML 파일 하나를 새 폴더에 넣고, 파일 이름을 index.html로 바꿉니다.
  2. vercel.com/drop을 열고 그 폴더를 화면에 끌어다 놓습니다.
  3. 프로젝트 이름(영문)을 정하고 Deploy를 누릅니다. 로그인하지 않고 올리면 임시 배포라 일정 기간 뒤 사라집니다.
  4. https://프로젝트이름.vercel.app 주소가 나오면 열어 확인합니다.
데스크톱인 경우 · AI에게 맡기기
  1. 수업 전에 vercel.com/signup에서 무료(Hobby) 계정을 만들어 둡니다. 이메일이나 GitHub 계정으로 가입할 수 있습니다.
  2. 아래 프롬프트를 보내면 AI가 Vercel 배포 도구를 실행해도 되는지 묻습니다. 내용을 읽고 허용을 누릅니다.
  3. 처음 배포할 때는 브라우저에 Vercel 로그인·승인 화면이 뜹니다. 가입한 계정으로 로그인하고 승인합니다.
  4. 배포가 끝나면 https://프로젝트이름.vercel.app 형태의 주소가 나옵니다. 휴대폰으로 열어 확인합니다.
데스크톱 · AI에게
이 폴더의 자기소개 페이지를 Vercel에 배포해줘.
처음이면 로그인 방법을 안내해 주고, 끝나면 접속 주소를 알려줘.
확인할 것
  • vercel.app 주소를 휴대폰으로 열면 내 페이지가 보이나요?
  • 옆 사람에게 주소를 보내 열리는지 확인했나요?
주의
  • 배포한 주소는 아는 사람 누구나 볼 수 있습니다. 개인 휴대폰 번호처럼 공개하면 안 되는 정보는 넣지 않습니다.
  • 데스크톱에서 Codex를 쓴다면 먼저 “Vercel에 배포할 수 있게 vercel-deploy 스킬을 설치해줘.”라고 보낸 뒤 배포를 맡깁니다.
5고치고 다시 배포
페이지를 한 군데 고친 뒤 다시 배포합니다. 웹은 고친 파일로 Vercel Drop에 다시 올립니다.
AI에게 · 색칠된 부분을 내 것으로
고칠 내용을 고치고 Vercel에 다시 배포해줘. 주소를 알려줘.
확인할 것
  • 같은 주소에서 고친 내용이 보이나요? 주소가 바뀌었다면 새 주소를 확인합니다.

1데이터 이해
웹은 새 대화에 판매 데이터.xlsx를 첨부하고, 데스크톱은 판매 데이터.xlsx가 든 폴더를 작업 폴더로 열고 시작합니다. 먼저 데이터 구조를 파악합니다.
AI에게
판매 데이터 엑셀 파일의 시트, 열 이름, 데이터 기간, 계산 열을 분석해 줘. 대시보드 제작에 필요한 핵심 열을 정리해 줘. 파일은 수정하지 마.
확인할 것
  • 데이터 기간이 엑셀의 첫 판매일자·마지막 판매일자와 맞나요?
  • 엑셀 수식으로 계산된 열(할인후단가, 실적매출액, 계획매출액 등)을 따로 구분했나요?
  • 원본 엑셀 파일이 바뀌지 않았나요?

AI에게
영업관리자가 월별 판매 실적과 계획 달성 현황을 확인하기 위한 KPI 4개를 제안해 줘. KPI는 실적매출액, 계획달성률, 계획 대비 차이, 매출총이익률을 포함해 줘.
확인할 것
  • KPI마다 계산식이 붙어 있나요?
  • 전체 계획달성률을 행별 달성률의 평균이 아니라 ‘실적매출액 합계 ÷ 계획매출액 합계’로 계산하나요? 평균을 내면 값이 달라집니다.
  • 매출총이익률은 ‘매출총이익 합계 ÷ 실적매출액 합계’인가요?
3화면 설계

AI에게
영업관리자용 판매 분석 대시보드를 한 페이지로 설계해 줘. 상단에는 필터, 중간에는 KPI와 월별 차트, 하단에는 제품·채널·지역별 성과 비교와 상세 데이터표를 배치해 줘. 아직 코드는 작성하지 마.
확인할 것

AI에게
방금 설계한 한 페이지 판매 대시보드를 단일 HTML 파일로 구현해 줘. 엑셀 파일 업로드, KPI 4개, 월별 실적·계획 비교 차트, 계획달성률 차트를 포함해 줘. 서버 없이 브라우저에서 실행되게 해 줘.

5조건 선택 기능
필터를 붙이고, 대분류에 따라 제품명이 좁혀지게 합니다.
AI에게

확인할 것

  • 조건을 바꿀 때 KPI·차트·비교표·상세표가 모두 함께 바뀌나요?
6비교·상세표 기능
제품·채널·지역별 비교와 상세표 기능을 더합니다.
AI에게
제품별, 채널별, 지역별 탭으로 계획 대비 차이를 비교하는 막대 차트와 비교표를 추가해 줘. 상세 데이터표에는 검색, 20·50·100행 선택, 이전·다음 페이지 기능을 추가해 줘.
확인할 것

7인사이트·알림
숫자와 차트만 있으면 ‘그래서 무엇이 문제인지’는 보는 사람이 찾아야 합니다. 처음 화면에서 무엇을 볼지, 어디가 문제인지 먼저 보이게 합니다.
AI에게
대시보드 맨 위에 '이 대시보드가 답하는 질문 3개'(계획 달성 여부, 부족한 곳, 먼저 챙길 것)를 넣어 줘.
그 아래에 현재 필터 조건으로 자동 계산되는 한 줄 결론 문장을 보여 줘.
예: "선택 기간 달성률 ○%, 계획 대비 ○원. 부족분의 ○%가 ○○ 채널입니다."
달성률이 95% 미만이거나 3개월 이상 연속 미달인 채널·제품·지역은
'주의' 카드로 빨간색 표시하고, 기준값은 화면에서 바꿀 수 있게 해 줘.
KPI 카드에는 100% 이상 초록, 95~100% 주황, 95% 미만 빨강 신호등을 붙여 줘.
기존 기능은 변경하지 마.

완성한 대시보드를 Vercel에 올립니다. 1번 실습에서 해 본 방법과 같습니다. 웹은 Vercel Drop으로 직접 올리고, 데스크톱은 AI에게 맡깁니다.
웹에서 만든 경우 · Vercel Drop으로 직접 올리기
  1. 완성된 HTML 파일 하나를 새 폴더에 넣고, 파일 이름을 index.html로 바꿉니다.

  3. 프로젝트 이름(영문)을 정하고 Deploy를 누릅니다. 로그인하지 않고 올리면 임시 배포라 일정 기간 뒤 사라집니다.

AI에게 · 차트 클릭으로 필터
차트의 막대나 점을 클릭하면 그 항목으로 필터가 걸리게 해 줘. 예를 들어 제품별 막대를 누르면 제품명 필터가, 월별 막대를 누르면 기간 필터가 그 값으로 바뀌고 KPI·차트·표가 함께 바뀌게 해 줘. 같은 막대를 다시 누르거나 필터 초기화를 누르면 풀리게 하고, 지금 걸린 필터를 화면 위에 표시해 줘.
AI에게 · 정렬 기능
제품·채널·지역 비교표에서 실적매출액, 계획달성률, 계획 대비 차이 열을 클릭해 정렬할 수 있게 해 줘.
AI에게 · 차트 개선
월별 실적·계획 차트에 데이터 레이블과 툴팁을 추가해, 마우스를 올리면 실적·계획·달성률을 확인할 수 있게 해 줘.
AI에게 · 다운로드 기능
현재 필터와 검색 조건이 적용된 상세 데이터표를 CSV 파일로 다운로드하는 기능을 추가해 줘.

웹에서 고친 내용이 반영이 안 된다새로 받은 HTML 파일로 바꿔 저장했는지 확인합니다. 예전 파일을 열고 있는 경우가 많습니다.

          
파일을 못 찾는다고 한다웹은 대화에 파일을 첨부했는지, 데스크톱은 작업 폴더가 파일이 든 폴더인지 확인합니다.

          
데스크톱에서 허용 창이 계속 뜬다파일을 만들거나 명령을 실행할 때마다 확인을 받습니다. 내용을 읽고 허용합니다.

          
결과가 기대와 다르다아래 틀로 무엇이 나왔고 무엇이 나와야 하는지 적어 보냅니다.

변경이 화면에 안 보인다브라우저에서 Ctrl+F5로 새로고침합니다.

판매 대시보드를 한 번에 만드는 통합 프롬프트

        
2번을 단계별로 해 본 뒤, 요구사항을 한 번에 다 적으면 어떻게 되는지 비교할 때 씁니다. 진도가 늦을 때 따라잡는 용도로도 씁니다. 판매 데이터.xlsx를 첨부하고 보냅니다.

        
AI에게 · 통합 프롬프트
첨부한 판매 데이터 엑셀로 영업관리자용 판매 분석 대시보드를 단일 HTML 파일로 만들어 줘.
서버 없이 브라우저에서만 동작하고, 엑셀 파일을 업로드하면 바로 분석되게 해 줘.

1. 데이터
- 먼저 시트, 열 이름, 데이터 기간, 계산 열을 확인하고 핵심 열을 정리해서 보여 줘. 파일은 수정하지 마.
- 판매 데이터는 HTML 안에 넣지 말고 업로드 방식으로만 읽어 줘.

2. KPI 4개
- 실적매출액, 계획달성률, 계획 대비 차이, 매출총이익률
- 계획달성률은 실적매출액 합계 ÷ 계획매출액 합계, 매출총이익률은 매출총이익 합계 ÷ 실적매출액 합계로 계산해 줘.
- 100% 이상 초록, 95~100% 주황, 95% 미만 빨강 신호등을 붙여 줘.

3. 인사이트
- 맨 위에 이 대시보드가 답하는 질문 3개(계획 달성 여부, 부족한 곳, 먼저 챙길 것)를 넣어 줘.
- 현재 필터 기준으로 자동 계산되는 한 줄 결론 문장을 보여 줘.
- 달성률 95% 미만이거나 3개월 이상 연속 미달인 채널·제품·지역은 '주의' 카드로 표시해 줘.

4. 화면 구성 (한 페이지)
- 상단: 기간, 대분류, 제품명, 채널명, 지역 필터. 대분류를 고르면 해당 제품명만 선택되게 해 줘.
- 중간: KPI, 월별 실적·계획 비교 차트, 월별 계획달성률 차트
- 하단: 제품별·채널별·지역별 탭으로 계획 대비 차이 막대 차트와 비교표, 상세 데이터표(검색, 20·50·100행, 이전·다음 페이지)
- 필터를 바꾸면 결론, KPI, 차트, 비교표, 상세표가 모두 함께 바뀌게 해 줘.

5. PDF 저장
- A4 가로, 인쇄 시 필터·버튼 숨김, 차트와 표가 페이지 중간에서 잘리지 않게, 상세표 헤더 반복

6. 디자인
- 흰 배경, 블루 계열, 충분한 여백, 카드형 KPI, 읽기 쉬운 한글 글꼴. 휴대폰에서도 보기 좋게.

7. 검증
- 완성 후 업로드 → 필터 → KPI → 차트 → 비교표 → 상세표 → PDF 저장까지 직접 확인하고,
  KPI 4개의 값과 계산식을 표로 보여 줘.

        
한 번에 시키면 AI가 화면 배치와 세부 계산을 알아서 정합니다. 마지막에 받은 KPI 값과 계산식 표는 엑셀에서 꼭 대조합니다. 웹에서 코드가 중간에 끊기면 “이어서 써줘”라고 보냅니다.

AI에게 · 내 데이터 통합 프롬프트 · 색칠된 부분을 내 것으로
첨부한 내 데이터 파일 이름으로 업무용 대시보드를 단일 HTML 파일로 만들어 줘.
이 대시보드를 볼 사람은 보는 사람, 예: 팀장이고,
알고 싶은 것은 예: 사업별 예산 집행이 계획대로 되고 있는지야.

1. 먼저 확인하고 제안하기 (여기서 멈추고 내 답을 기다려 줘)
- 시트, 열 이름, 데이터 기간, 계산 열을 정리해 줘. 파일은 수정하지 마.
- 개인정보로 보이는 열이 있으면 알려 줘.
- 보는 사람이 꼭 봐야 할 KPI 4개를 계산식과 함께 제안해 줘.
- 필터로 쓸 열, 비교 기준 열(예: 부서별, 월별), 이 대시보드가 답해야 할 질문 3개를 제안해 줘.

2. 내가 확인하면 만들기
- 서버 없이 브라우저에서만 동작하게 하고, 데이터는 HTML 안에 넣지 말고 엑셀 업로드 방식으로만 읽어 줘.
- 맨 위: 질문 3개와 현재 필터 기준 한 줄 결론 문장
- KPI 카드 4개: 기준 대비 좋음·주의·나쁨을 초록·주황·빨강으로 표시
- 기준에 못 미치는 항목은 '주의' 카드로 표시하고, 기준값은 화면에서 바꿀 수 있게
- 월별 추이 차트, 비교 기준별 막대 차트와 비교표, 상세 데이터표(검색, 20·50·100행, 페이지 이동)
- 필터를 바꾸면 결론, KPI, 차트, 표가 모두 함께 바뀌게
- PDF 저장 버튼(A4 가로, 인쇄 시 필터·버튼 숨김)
- 흰 배경, 차분한 블루 계열, 휴대폰에서도 보기 좋게

3. 검증
- 완성 후 업로드 → 필터 → KPI → 차트 → 표 → PDF 저장까지 직접 확인하고,
  KPI 4개의 값과 계산식을 표로 보여 줘. 내가 엑셀에서 직접 대조할 거야.

        
    
          
  1. 1번 제안이 나오면 “KPI는 ○○로 바꾸고 나머지는 좋아. 만들어 줘.”처럼 답합니다. 고칠 게 없으면 “좋아, 만들어 줘.”라고만 보냅니다.
    2.
